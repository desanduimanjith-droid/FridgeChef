🥗 FridgeChef
FridgeChef is an AI-powered culinary assistant designed to eliminate food waste and solve the "what's for dinner?" dilemma. By simply entering the ingredients you already have, FridgeChef suggests perfect recipe matches using intelligent filtering and modern UI design.

🎯 Purpose
The goal of this project is to provide a seamless, visual experience for home cooks to:

Reduce Food Waste: Use what you have before it expires.

Save Money: Avoid unnecessary grocery trips.

Discover Recipes: Find creative ways to use common household staples.

🛠 Tech Stack

Frontend
Framework: Next.js 14+ (App Router)

Styling: Tailwind CSS for a modern, responsive design.

Animations: Framer Motion for smooth transitions and interactive elements.

Icons: Lucide React for clean, consistent iconography.

Backend

Runtime: Node.js

Framework: Express.js

Database: (Planning to use firebase)

🔌 APIs & Services

Internal Recipe API: A custom Node.js REST API that calculates "Match Percentages" based on user input vs. recipe requirements.

AI Integration (Planned): Integration with OpenAI (GPT-4o) or Google Gemini API to generate recipes dynamically when no database match is found.

Image Hosting: High-quality food photography sourced via Unsplash API.

✨ Key Features

1.Smart Ingredient Tags: Add and remove ingredients with a fluid, pill-based UI.

2.Match Logic: View exactly how well a recipe fits your fridge (e.g., "100% Match").

3.Responsive Design: Fully optimized for mobile, tablet, and desktop viewing.

4.AI Suggestions: Real-time feedback and ingredient "freshness" detection.

🚀 Future Roadmap//

 User Authentication: Save "Favorite" recipes to a personal profile.

Shopping List: Automatically add missing ingredients for a 90% match recipe to a list.

Voice Input: Use the Gemini Live-style voice interaction to tell the app what's in your fridge.

Dark Mode: A sleek nocturnal mode for late-night cooking.
